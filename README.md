## Folder Structure

Each subject has the same simple structure:

```text
Subject/
├── Notes/
├── Quizzes/
├── Assignments/
├── Resources/
└── README.md
```

For lab courses:

```text
Lab Subject/
├── Lab-01/
├── Lab-02/
├── Quizzes/
├── Assignments/
├── Resources/
└── README.md
```

## How I will update it

After a class, I can simply open the relevant subject folder and add files manually.

Examples:

```text
CSC-2102-Data-Structures-and-Algorithms/
├── Notes/
│   ├── Lecture-01-Introduction.md
│   └── Lecture-02-Arrays.md
├── Quizzes/
│   └── Quiz-01.md
├── Assignments/
│   └── Assignment-01.md
└── Resources/
    └── Recommended-Book.md
```

For PDFs, PowerPoints, images, code, or other files, place them directly in the appropriate folder.

## Suggested naming

Use simple names such as:

- `Lecture-01.md`
- `Lecture-02.md`
- `Quiz-01.md`
- `Assignment-01.md`
- `Lab-01.md`
- `Midterm-Important-Questions.md`

You can also use dates:

- `2026-09-25-Lecture-01.md`
